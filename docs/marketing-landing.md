# 商业化宣传页方案

宣传口号：**与其忘记上一条视频刷了什么，不如花上三分钟了解一下世界发生了什么。**

本文是方案，尚未改动线上页面。目标是让短视频带来的访客在一屏内理解价值，在第二屏完成“填邮箱、选主题、开始试读”，之后由邮件和个人主页承担留存与付费转化。

## 1. 定位与口径

- **用户场景**：刷完一小时视频，想不起看了什么。产品不和短视频争时间，而是把零碎信息沉淀成三分钟能读完的东西。
- **一句话价值**：每天早 8 点、晚 8 点，两封三分钟文字简报，三条必知、为什么重要、一个观察点，附原始来源。
- **可以说的**：每封约三分钟、附来源、15 个主题自选、免费试读 3 封、周付 3 元、随时退订、财经内容只讲事实不荐股。
- **不要说的**：用户数量、好评、“最”“第一”“权威”、保证提高收入或判断力。目前没有可核实的数据，宣传页不放虚构的数字或评价。
- **AI 披露**：保留“AI 辅助摘要，请以原始来源为准”，放在页脚和每期内容旁。

## 2. 首屏

| 元素 | 方案 |
| --- | --- |
| 主标题 | 与其忘记上一条视频刷了什么，<br>不如花上三分钟，了解世界发生了什么。 |
| 副标题 | 北京时间每天 08:00、20:00，一封三分钟文字简报。三条必知，说清为什么重要，附原始来源。 |
| 主按钮 | 免费试读 3 期 |
| 次按钮 | 先看看今天这一期 |
| 邮箱输入 | 直接放在首屏，一个输入框加按钮。选主题放到提交之前或确认之后，不挡在第一步 |
| 信任行 | 附原始来源 · 不荐股 · 15 个主题自选 · 随时退订 |
| 视觉 | 保持现有鼠尾草绿、森林绿、赤陶色和衬线字体。右侧用真实的最新一期做报纸样式预览，替换现在的结构示意 |

主标题较长，桌面分两行，手机分三行，字号控制在 34 至 40 像素。短版“三分钟，补全今天的世界。”留给导航、分享卡片和短视频封面。

## 3. 页面结构

1. **首屏**：口号、邮箱、试读按钮、今日一期预览。
2. **对比块**：左侧“刷了一小时，还记得什么？”，右侧“三分钟，记住三件事”。只用文字对比，不放未经核实的统计。
3. **今天这一期**：展示最新一期的 3 条真实内容，结构为标题、摘要、为什么重要、来源链接，底部提示“订阅后按你的主题排列”。这一块同时是可被搜索和分享的公开页面。
4. **三步开始**：选主题，确认邮箱，每天早晚各收到一封。注明试读按邮件封数计算。
5. **15 个主题墙**：主题以标签呈现，点击即预选，并滚动到邮箱框。强调“可以一个都不选，收通用版”。
6. **价格**：周付 3 元、月付 9.9 元、季付 29 元、年付 99 元。每张卡片显示折合每天价格，周付约 4 角 3、月付约 3 角 3、季付约 3 角 2、年付约 2 角 7。默认突出月付，周付作为低门槛入口。
7. **常见问题**：邮件会不会太多、内容怎么来的、是不是 AI 写的、怎么退订、怎么付款、过期会怎样、财经内容算不算投资建议。
8. **收尾**：再放一次口号和邮箱框。
9. **页脚**：隐私政策、服务条款、联系邮箱、AI 披露、免责声明。

价格标题中的“清醒”属于感受性表达，上线前建议按广告法口径复核，必要时改为“一天不到三毛”。

## 5. 获客与转化

- **短视频导流**：每条视频落地到带来源参数的链接，例如 `/?src=douyin&c=0001`。页面读取参数并保存，订阅时随申请一并记录，用于计算渠道转化。当前代码没有这一项。
- **公开的今日一期页**：新增 `/today`，展示最新一期的 3 条，附订阅入口。可被搜索引擎收录，也方便读者转发。需要一个只读公开接口，只返回 3 条且不含个人数据。
- **分享卡片**：个人主页每条内容提供“分享这条”，生成带口号的图片卡片，回流到 `/today`。
- **邀请有礼（后续）**：朋友确认邮箱后，双方各多 1 封试读。需要新增邀请码字段和防刷规则，此阶段只做设计。
- **个人主页里的转化位**：试读剩余提示、到期前 3 天提醒、过期后的“只看最新一期”预览。这三处已有数据，后续只需调整文案和按钮位置。

## 6. 指标与埋点

漏斗：访问首页，选择主题，提交邮箱，确认邮箱，收到第 1 封，试读用完，付费，续费。

需要新增的事件：落地页浏览、主题勾选、提交申请、确认成功、个人主页访问、内容流切换、价格卡点击、订单创建、支付成功。建议记录在自有数据库，不引入第三方脚本，以免与现有严格的内容安全策略冲突，也方便说明隐私口径。仓库根目录已有 `analytics_schema.sql`，可参考其结构。

## 7. 上线前必须补齐

1. **隐私政策与服务条款页面**。目前订阅框的同意文字没有链接到它们，需要说明收集的邮箱和偏好、保存期限、退订与删除方式。
2. **备案与域名**。面向中国大陆提供服务，需要确认备案要求和托管位置。
3. **发信域名认证**。为发件域名配置 SPF、DKIM、DMARC，否则大概率进入垃圾箱，试读转化会很差。
4. **支付与退款规则**。写明按时长计费、手动续费、到期不自动扣款，以及退款方式。退款目前需在支付宝商户后台人工处理。
5. **财经与健康内容声明**。页脚和相关邮件注明“仅整理事实，不构成投资或医疗建议”。
6. **真实内容回填**。首页预览和 `/today` 必须来自已冻结的真实快照，不使用虚构示例。

## 8. 建议的实施顺序

1. 隐私政策、服务条款页面，并在订阅框链接。
2. 首屏改版：口号、行内邮箱、信任行、价格折合每天。
3. `/today` 公开页与首页真实预览。
4. 渠道参数记录与漏斗埋点。
5. 分享卡片与邀请机制。

每一步都应当单独验证并提交，沿用本仓库的测试和浏览器验收标准。
